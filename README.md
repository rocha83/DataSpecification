# Rochas.Data.Specification

**Rochas.Data.Specification** é o orquestrador de contratos do *toolkit de gestão de dados Rochas* — a camada única, sem dependências, que une `Rochas.DapperRepository`, `Rochas.BWOQ`, `Rochas.SqlWrapper` e `Rochas.CacheIndexer` sob um mesmo vocabulário de anotações, enums e interfaces.

Ela substitui o `Rochas.DapperRepository.Specification` (1.5.2, mantido no NuGet apenas como legado).

---

## 📌 Instalação

```bash
dotnet add package Rochas.Data.Specification
```

---

## 📌 O que contém

| Área | Conteúdo |
|------|----------|
| `Annotations` | `Listable`, `Filterable`, `RangeFilter`, `RelatedEntity`, `AutoGenerated`, `DataAggregationColumn`, `RelationalColumn`, `Cacheable` |
| `Enums` | `DatabaseEngine`, `PersistenceAction`, `DataAggregationType`, `RelationCardinality`, `RelationalJunctionType` |
| `Interfaces` | `IPersistenceRepository<T>`, `IGenericRepository<T>`, `IGenericBwoqRepository<T>`, `IBwoqQueryBuilder<T>`, `IQueryBuilder<T>`, `IQuerySyncBuilder<T>`, `IQueryPaginatedBuilder<T>`, `IRelatedEntity` |
| `Models` | `PaginatedResult<T>`, `GroupResult<TKey, TItem>` |

## 📌 Hierarquia dos contratos de repositório

```text
IPersistenceRepository<T>                        # persistência pura (Add/Update/Remove/Get/Count/QueryRaw)
  ├── IGenericRepository<T>                      # + Search/Query/OrderBy/GroupBy (builders de consulta)
  └── IGenericBwoqRepository<T>                  # + QueryBwoq() → IBwoqQueryBuilder<T> (gramática Q/W/G/O/OD)
```

## 📌 Uso BWOQ (gramática Q/W/G/O/OD)

```csharp
using Rochas.Data.Specification.Interfaces;

IGenericBwoqRepository<Pessoa> repo = /* seu repositório */;

var result = await repo.QueryBwoq()
    .Q("3")                // projeção (máscara de bits)
    .W("4::carlos")        // critério LIKE
    .O("2")                // ordenação
    .ToQuery();
```
